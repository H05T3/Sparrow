# Welcome to Sparrow

## What is Sparrow?
+ Sparrow is my web app project for my CS311 class. This is a submission for project 2 of this class.
+ Sparrow is a website using a bird API to help new bird watchers help find information about birds and any specific information that the API can help find. Sparrow will be able to show an image of the bird you search up, the name, the specifics of birds, and if I have time maybe I'll add an example call for each bird. 

## Why Sparrow?
+ House sparrows are probably the most common birds I see outside, and my girlfriend Ciara is a advocate bird watcher and whenever I ask her what type of bird something is, it always ends up just being a type of sparrow. I want to get on-par with my girlfriend in identifying birds here in Indiana, so I'm creating this site to not only test my web development skills but to also help me learn more about birds myself.
